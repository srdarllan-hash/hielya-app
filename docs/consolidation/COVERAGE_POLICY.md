# HIELYA — Coverage Baseline Policy

The consolidation branch records real V8 coverage for statements, branches, functions and lines through:

```bash
pnpm test:coverage
```

No minimum threshold has been approved in the official product documentation.

```text
COVERAGE_THRESHOLD = PENDING_DECISION
```

The current measured baseline is evidence, not a silently invented acceptance threshold. A future threshold change requires an explicit governance decision, manifest update and Gate rerun.
